- [2026-09-30] Where Chromium's sandbox couldn't start, Playwright 1.63's `launch` raised `TargetClosedError: Target page, context or browser has been closed`, which names no cause → Chromium's zygote aborts before the browser connects, and the cause, `No usable sandbox!`, appears only in the browser log that Playwright appends to the message → recognize the failure by that log line, as `aqa_runner.sandbox.launch` does, and pass every other launch error through unchanged.
- [2026-09-30] `python3 .claude/hooks/policy_guard.py --scan` exited 0 inside a Claude Code session on a tree with a planted `# type: ignore` → the maintainer's local settings set `AQA_POLICY_GUARD=off`, which Claude Code passes to every shell, and `main()` returned 0 on it before dispatching any mode, so a scan run by hand checked nothing → the switch now silences only the hook entry points; an explicit `--scan` always runs (`test_escape_hatch_leaves_an_explicit_scan_on`).
- [2026-09-29] Once a guard test ran `--scan` as a subprocess from a temp directory, `uv run pytest --cov` fell from 94% to 84.10%, with the omitted `bench/harness/toggle_checks.py` reported at 0% → coverage 7.16.2 makes an `omit` pattern that doesn't start with a wildcard absolute against each process's cwd (`files.py`, `prep_patterns`), and `patch = ["subprocess"]` hands children the pattern as written, so a child started elsewhere doesn't omit the file and adds it to the combined data → start every `omit` pattern with `*/`; `tests/test_constraints.py` runs a child from another directory to prove it.
- [2026-09-29] A module planted in `packages/core/src/aqa_core/` that no test imports was missing from `pytest --cov`'s report, so it couldn't lower the total → coverage 7.16.2 skips directories without an `__init__.py` when it searches for files no test imported (`files.py`, `find_python_files`), and workspace members have none above `src/` → set `[tool.coverage.report] include_namespace_packages = true` (ADR-0028). To check it, plant an unimported module and look for it in the report.
- [2026-09-29] A `pytest --cov` run at 93.60% printed `FAIL Required test coverage of 94.0% not reached` and exited 0, with the report showing 94% → pytest-cov 7.1.0 prints that line from the unrounded total, but takes its exit code from coverage's `should_fail_under`, which first rounds to `precision` (0 here) → judge a coverage run by its exit code and by the `Coverage failure: total of N is less than fail-under=M` line, which only a failing run prints.
- [2026-09-29] A test for Ruff's `BLE001`/`S110` passed before either rule was selected, and the curated `select` for #59 would have stopped 72 rules that already ran (PYI, YTT, `TC004`, `PGH005`, …) → Ruff 0.16.9's default set is 413 rules, not just E4/E7/E9/F, and `select` replaces it instead of adding to it → before changing `select`, diff the enabled rules in `ruff check --show-settings <file>` against the new list, and keep the defaults you mean to keep (ADR-0028).

- [2026-09-29] A Playwright 1.63 route handler installed on the context saw a redirect's first request (`/redir`, a document) but never the hop to the second host, and the page landed there → `context.route` intercepts the request that starts a redirect chain, not the redirected requests → never rely on routing alone for egress or for which documents the agent may use: the egress proxy sees every hop, and the tools check the page's origin before each observation and action (ADR-0026).
- [2026-09-29] A case-sensitive literal text check would fail a harmless restyle: `inner_text()` returned `'POST COMMENT'` for a button styled `text-transform: uppercase`, while its accessible name stayed `Post Comment` → Chromium's rendered text (`innerText`) applies CSS `text-transform`, and accessible names don't → compare `text` checks case-insensitively and at word boundaries (ADR-0025); role-and-name locators are unaffected.
- [2026-09-29] `Locator.normalize()` returned `internal:role=link[name="\uf218\xa0New Article"i]` for a Conduit-style icon link, a bare `form` for a form, and a text locator for a `<nav>` → accessible names include icon-font glyphs from CSS `::before`, and `normalize()` picks the shortest selector that is unique now, not one that stays stable → our compiler builds locators itself: glyphs stripped, scoped, validated at every use (ADR-0025).

## Watch list (known risks to verify early)

- A heal can route around a broken UI path and still satisfy every expectation. In the pilot, `conduit-bug-005` covers the header's "New Article" link, so `publish-article` can't click it; a heal that replaces the click with `navigate("/editor")` meets every expectation while real users stay stuck. Decide at M2 whether the heal-patch validator may replace an interaction step with direct navigation. Until then, the manifest leaves such specs unscored (DATA_MODEL §8).
- The benign pilot cases heal only if M1 compiles for meaning, not for today's markup. A heal may rebind a target but never rewrite an assertion or a target's meaning (DATA_MODEL §7).
  - `conduit-benign-001` relabels the Post Comment button, so that target's meaning should be "the comment form's submit button", not its label.
  - `conduit-benign-002` moves the favorites count out of the Favorite button. The count's target must be the count itself, not the button, and its pattern must match the claim (`\b1\b`), not the clean rendering (`\(1\)`).
  - Otherwise these cases score `inconclusive` or `expectation_violated` against their `drift_consistent` ground truth. Check the compiled pilot scripts for this at M1.
  - Decided in ADR-0025 (label-free meanings, claim-independent locators for assertion targets, whole-word `text` checks). M1's pilot acceptance checks it (ROADMAP M1 exit). A validated fallback locator may absorb `conduit-benign-001`, so its scoring depends on #25.
- Upstream's Conduit E2E suite fails 26 of 139 tests against the vendored app, every run, for reasons not yet known (`bench/apps/conduit/README.md`, "Open item"). If they are real bugs in the clean app, a spec over those flows (mostly error handling) would count them as false positives, so the pilot specs avoid those flows. Explain the failures before M3 writes specs that cover them.
- Rendered dates depend on the browser's time zone, so benchmark browsers run in UTC (TESTING §5). The toggle checks pin it, and so does every run's browser session (#36), unless the project or a spec overrides it (ADR-0025). An override outside UTC−10 to UTC+13 makes `read-article`'s date expectation and `conduit-bug-001` fail on the clean app.
- Hosted compute for sandboxed Chromium: Lambda functions can't create user namespaces, and Fargate can't take a custom seccomp profile, so neither is likely to run the sandbox. The M1 spike tests a Lambda MicroVM, a Fargate task and a Lambda function against the fresh-VM rule (ADR-0008 amendment, 2026-09-29). It measures time to a ready browser, memory and cost, including snapshot storage and reads.
- Warm Lambda environment reuse: `/tmp` and surviving processes persist across invocations (and timeouts don't clear `/tmp`) — startup hygiene must run before any tenant data is fetched; crash-reuse tests must pass on real Lambda, not only the emulator. This no longer applies if the spike picks a fresh VM per run, as the 2026-09-29 rule requires.
- GitHub's ubuntu-24.04 runners block Chromium's sandbox through AppArmor (`kernel.apparmor_restrict_unprivileged_userns=1`). Our CI records the setting, then relaxes it before browser tests (ADR-0026). Check that the same step works on a Blacksmith runner before switching `CI_RUNNER` (ADR-0019).
- LangGraph checkpoint serialization size through the API: the binding limit is Lambda's **6 MB** synchronous payload (not API Gateway's 10 MB); keep checkpoints ≤ 1 MB compressed and large values in S3.
- Playwright request routing and service workers: service workers can bypass routing — keep them blocked; verify WebSocket routing coverage in the Playwright version pinned. Routing also misses redirect hops (2026-09-29 entry above).
- Clerk client-only auth inside a Next.js static export (no middleware) — proven in the M7 skeleton.
- Stubbing model providers in tests: respx 0.23.1 patches only `httpx`, but `anthropic` 1.9.0 and `openai` 3.22.0 send requests through `httpx2`, Pydantic's continuation of HTTPX. A respx stub never sees their calls, so a test can reach the real API with whatever key is set. Record provider traffic with VCR.py (8.3.0 patches `httpx2`) or give the SDK a test transport. Resolved by #40: the router's tests replay VCR cassettes (`packages/runner/tests/conftest.py`, `cassette`).

## Resolved during design review (2026-09-27)

- Clerk session token v2 carries the active org as `o.id`, a string like `org_2abc…` — not a UUID. Map via `organizations.clerk_org_id` → internal UUID before setting `app.org_id`.
- psycopg 3 can't bind parameters in `SET LOCAL`; use `SELECT set_config('app.org_id', %s, true)`.
- Amplify Hosting SSR supports Next.js 12–15 only (as of 2026-09-27) → dashboard ships as a static export on S3 + CloudFront (ADR-0017).
- GitHub Checks: ≤ 3 actions per check run; action identifier and label ≤ 20 characters; description ≤ 40 → per-spec check runs with short opaque action tokens.
- API Gateway WebSocket: authorizers run only on `$connect`; 2-hour max connection, 10-minute idle timeout → authorize every subscribe in app code; heartbeats; reconnect with `since_seq`.
- Playwright launches Chromium with `--no-sandbox` unless `chromium_sandbox=True`; on Lambda the sandbox typically fails ("No usable sandbox!") → M1 decision gate between Lambda and per-run Fargate for hosted runs.
- GitHub OIDC: `job_workflow_ref` identifies a *reusable* workflow; ordinary workflows are identified by `workflow_ref`/`workflow_sha`. For `pull_request` events the `sha` claim is the merge commit, not the PR head → store execution SHA and head SHA separately.
- Zero flakes in 30 specs × 20 replays only bounds the pooled rate at ≤ 0.50% if replays are independent; with full within-spec dependence it's 30 independent outcomes (≤ 9.5%). Report both; bootstrap bounds on all-zero data are degenerate.
- Playwright page/context routing alone doesn't give connection-level egress control (WebSockets need `route_web_socket`, service workers bypass routing, DNS can rebind) → in-runner egress proxy with validated-IP connects as the primary control.
